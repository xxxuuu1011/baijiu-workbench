# 白酒私域电销运营工作台

京东酒水私域项目的运营工作台，纯静态站点（无需后端），部署在 GitHub Pages 上。

## 访问

`https://<用户名>.github.io/<仓库名>/`

这个域名**永久固定**，不会因为重新发布而改变。

## 页面

| 文件 | 说明 |
|---|---|
| `index.html` | 工作台主页面（各业务板块 + 笔记纪要 + 备忘录） |
| `migrate.html` | 数据迁移页（跨域名搬运笔记/分类/备忘录） |
| `data.js` | 各板块内容数据（每日更新） |

## 数据存储说明

- **笔记 / 分类 / 备忘录**保存在浏览器 `localStorage`，按域名隔离，**不上传服务器**。
- 工作台内置「本地文件存档」：可把数据写入本机一个 `白酒工作台数据.json`，换域名/清缓存后用「从文件还原」找回。
- 建议同时保留一份导出备份（笔记页「导出JSON」、备忘录页「导出备份」）。

## 更新方式

改动 `index.html` / `data.js` 后提交推送，GitHub Pages 会自动重新构建（约 1 分钟）。
`sw.js` 对 `index.html`、`data.js` 采用**网络优先**策略，因此刷新即可拿到最新内容。
